# PHP Calculator

A simple web-based calculator built with PHP for [Your Course Name].

## How to run
1. Make sure PHP is installed (`php -v` to check).
2. Run: `php -S localhost:8000`
3. Open `http://localhost:8000` in your browser.

## Features
- Basic operations: addition, subtraction, multiplication, division
- Input validation
- Includes an intentionally "ugly" function (`doStuff`) as required for the assignment
